Packages for SAEngine, the open-source structural engineering IDE. Install them from SAEngine's Packages page.

Design codes

BNBC 2020
v1.1.0BDAGPL-3.0-only
Bangladesh National Building Code 2020: Part 6 (Structural Design: loads, wind and earthquake, load combinations, reinforced concrete, seismic detailing, structural steel and foundations), Part 8 (plumbing, air-conditioning, electrical services), Part 4 (fire protection) and the standard steel sections SAEngine designs with. The values SAEngine used before code packs, transcribed from its modules; every table names its clauses and pages.
SAMPLE regional code (synthetic, not for design)
v0.1.0BDCC0-1.0
A SAMPLE of a regional design code package for authors to copy: it extends BNBC 2020 and adds two FICTIONAL towns with made-up seismic zones and wind speeds. The values are synthetic, come from no code or gazette, and must never be used for design.

Structure templates

SAEngine shapes
v1.1.0CC-BY-4.0
Presets of the seven parametric shapes built into SAEngine (space truss, plane truss, arch, dome, barrel vault, cable net, portal frame): their starting values in the Generate panel, and a few named variants. The shapes themselves are part of SAEngine; this package holds only their parameters.

Building templates

Dhaka 6-storey residential, 3 × 2 bays
v1.0.1BDCC-BY-4.0
The New Building wizard's starting values: an RC frame of 3 bays of 6 m by 2 bays of 5 m, 6 storeys (ground 3.6 m, typical 3.2 m), C27.6 concrete and B420DWR bars, isolated footings, residential use (occupancy category II) in Dhaka on an assumed site class SD until a soil report gives one. The generator sizes the members; designs follow BNBC 2020.
